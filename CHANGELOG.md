# Changelog

## 0.4.0
- Every refund now waits for a person's approval; declined refunds are reported to the customer.
- Each run stops after 12 steps, and each model call times out after 30 seconds.
- Dependencies are pinned to exact versions; tests run in CI with a scripted model.

## 0.3.0
- Tools describe what they do and when to use them, with typed inputs.
- Failures are reported back instead of being silently dropped.

## 0.2.0
- README: purpose, limits and how to run. Apache 2.0 licence and a security policy.
